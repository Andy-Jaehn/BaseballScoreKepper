## ER、自动判定与记录事实

ER 使用不含失误的半局影子记录重建，保留责任投手和换投时的实际出局数。因失误提前得分的跑者继续留在影子垒位，后续合法进垒若足以使其得分，会追溯确认为 ER。失误本应形成第三出局时，原投手后续失分不计 ER；接替投手从入场时的实际出局数建立独立记录。

无法从飞行轨迹推断裁判意图，因此“内野高飞球”在野手处理阶段记录裁判宣告；牺牲触击从触击球和跑垒结果判定；第三出局为时间触杀时，在出局录入中记录得分/出局先后，结果页不再要求输入 RBI 或统计结论。

每个球员在同一次击球中被选择为失误野手时合计一次 E，多个跑者因同一野手失误进垒不会重复累计 E。极端复杂的多次独立同人失误、盗垒、暴投、捕逸、不死三振、妨碍等仍不在本次记录模型范围内。影子跑者缺乏后续实际进垒观测时，仅按后续安打保守前进；不声称取代所有场景的官方记分员判断。
