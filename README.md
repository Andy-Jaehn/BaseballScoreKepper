## 钻石计分是一款简易的本地棒球计分软件。它有基于打席的方便快捷的计分系统，界面简单易懂、操作流畅，支持累加统计同一球员横跨多场的比赛数据，以及自动计算高阶数据。

### 使用说明  

1. 添加球员
   在主界面点击“球员”，添加姓名、背号（可选）、打击手和投球手。姓名不能重复。
   打击手：L 为左打，R 为右打，S 为左右开弓。球员可以编辑或删除，历史比赛数据保留。
2. 开始比赛
   选择“开始棒球比赛”或“开始垒球比赛”，再选择本场记录者、裁判，两者可以是同一人。
   搜索球员加入两队，按住 ≡ 拖动调整打击顺序，选择守备位置，确认主客队后点击“进入比赛”。慢投垒球可设置第十个位置“自由人”。
3. 记录投球
   - B：坏球。
   - S：好球。
   - Foul：界外球。
   - Fair：界内球，进入击球处理流程。
   B/S/O 分别表示坏球、好球和出局数。垒包灯红色表示有人。
   四坏球或三振成立后，会弹出结果确认。点击确认应用结果；点击“取消本球”恢复上一球状态。慢投垒球从 1 坏球、1 好球开始，两好球后的界外球也判出局。
4. 记录界内击球
   点击 Fair 后，依次记录：
   落点 → 飞行方式 → 处理野手与结果 → 跑者情况 → 确认结果。
   跑者按三垒、二垒、一垒、打者的顺序处理，可记录正常进垒、失误进垒、封杀或触杀。后位跑者不能超过前位跑者。
   正常进垒和失误进垒可以分别填写。例如“正常进 2 垒＋失误进 1 垒”，表示二垒安打后因失误到三垒。安打、野手选择、牺牲打、RBI 等由软件根据记录计算。
5. 撤销、查看记录与换人
   “撤销记录”可撤销当前未结束打席内的 B、S、Foul，不能跨越已经完成的打席。
   “逐球记录”显示球队、投手、打者及结果，最新记录在最上方。
   “守备换人”可更换当前守备球员或交换位置。替补继承被替换球员的打击棒次。
6. 特殊情况与裁判判罚
   点击右上角 ⋮ 菜单，可记录触身球、故意四坏球或打开裁判判罚。
   本软件禁止满垒时使用故意四坏球，但普通四坏球和触身球保送仍可记录。
   判罚可以让垒上跑者前进 1、2、3 垒、保送当前打者、判跑者出局或驱逐人员。驱逐场上球员后需选择替补，替补继承其位置和棒次。所有判罚均需确认后生效。
7. 结束比赛与查看统计
   三出局后点击“开启下个半局”，或点击“结束比赛”。也可通过右上角菜单结束比赛。
   赛后页面按队伍展示打击、投球和守备数据，可导出本场 Excel。主界面的“记录查看”可按年份查看或删除比赛；删除比赛会同步移除该场对球员累计统计的贡献。
8. 年度统计与备份
   在“球员”页面选择年份及棒球/垒球，可查看对应年度统计并导出 Excel。
   在“记录查看”中点击“按年导出 JSON”，可以多选年份备份已完成比赛。点击“导入比赛 JSON”恢复记录：重复比赛自动跳过，缺少的球员自动加入注册表并提示，导入比赛正常计入统计。

### 软件离线使用，操作会实时保存；意外退出后重新打开，可以继续未完成的比赛。
