# 2.0 规则依据与计算范围

查阅 MLB 官方 2026 规则：

- [官方规则册](https://mktg.mlbstatic.com/mlb/official-information/2026-official-baseball-rules.pdf)，尤其是 5.08、9.04–9.16。
- [场地尺寸](https://www.mlb.com/glossary/rules/field-dimensions)：内野为正方形，两条界线形成直角。软件采用 90° 扇形的抽象外野，而不是复制某座球场围栏。
- [ERA](https://www.mlb.com/glossary/standard-stats/earned-run-average)、[OPS](https://www.mlb.com/glossary/standard-stats/on-base-plus-slugging)、[双杀](https://www.mlb.com/glossary/standard-stats/double-play)。

## 投球与打席

棒球从 0–0 开始，四坏球保送、三好球出局。两好球后的普通界外球不再增加 S，但仍是一次实际投球和一次好球投球。慢投从 1–1 开始，两好球后的界外球同样保持两好球、不计出局；初始虚拟球数不增加 P 或 STR。2.1.2 起新记录采用这一规则，已保存的旧结果不追溯改写。

每个投球保留时间、投手、守备队、局数和打席编号。打席中未完成的 B/S/Foul 可撤销；完成打席后锁定。新 Fair 的落点、球型、野手、跑垒在固定弹窗中记录，结果页只读。

## 击球结果

正常进垒和失误额外进垒分别储存。打者正常前进两垒、因失误再进一垒，计 2B、TB=2，并记录 E，最终站三垒。

软件根据野手处理、球型、出局和进垒推断 H、FC、E、SF、SH 和 RBI。触击球结合两出局前推进跑者且无前位跑者出局的情况判定 SH。内野高飞必须录入裁判宣告，并验证两出局前一、二垒有人等基础条件，不只凭落点猜测。

滚地封杀双杀默认不计 RBI，失误造成的额外得分不计该打者 RBI。出局数和参与野手用于 DP/TP 统计。确认页显示高飞、内野高飞、接杀、地滚、双杀或三杀等结果。得分与非封杀第三出局的先后，是跑者出局步骤中的事实输入；封杀第三出局、打者到一垒前成为第三出局均取消本球得分。

场地规则一/二/三垒安打为用户要求的场地约定入口，自动为每位跑者推进对应垒数；不把自定义的一、三垒奖励说成 MLB 通用规则。全垒打使全部跑者及打者回本垒。

## ER 与统计

以 9.16 的去除失误重建半局原则，维护责任投手的影子跑垒和出局记录。支持失误本应造成第三出局、失误额外进垒、后续安打追溯 ER、继承跑者、FC 转移投手责任以及新投手不继承过去漏接出局机会等情形。

```
AVG = H / AB
OBP = (H + BB + HBP) / (AB + BB + HBP + SF)
SLG = TB / AB
OPS = OBP + SLG
FPCT = (PO + A) / (PO + A + E)
WHIP = 3 × (HA + BBA) / OUT
ERA（棒球）= 27 × ER / OUT
ERA（慢投）= 21 × ER / OUT
IP = floor(OUT / 3) + '.' + OUT % 3
P-S = 实际投球数 - 实际好球投球数
```

分母为 0 时沿用界面数值 0。累计比率从所有比赛原始分子、分母计算，不平均逐场比率。本局打击摘要只从当前局的打席派生，不另行累加到球员生涯数据。

## 特殊情况与边界

当前记录模型支持暴投 WP、捕逸 PB、投手犯规 BK、牵制尝试 PICK、盗垒 SB、盗垒失败 CS、双盗垒 DS、捕手妨碍 CI、不死三振 D3K，以及相应的 PO、A、E 归属。牵制和盗垒要求垒上至少有一位跑者；慢投垒球禁用 HBP、暴投、捕逸、牵制、不死三振、捕手妨碍打击和盗垒。

复杂场景仍依赖记录事实，软件不取代官方记分员；不自动宣告结束比赛。影子跑者缺少可观测进垒时按后续安打保守前进。同一野手同一次击球的多个跑者失误进垒合计一次 E，不区分该野手在同次击球中发生多个独立失误的极端情况。申诉、特殊竞赛条例及无法从输入唯一确定的官方裁决，应由记录者复核。

旧版记录中的人工统计修正保留读取，新版比赛忽略手工统计覆盖字段。详细更改与验证见 [2.0 说明](CHANGELOG-2.0.md)。
