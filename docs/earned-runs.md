# 影子局与 ER 判定

`replay(game).earnedRunAudit` 返回逐分依据，不改变界面、输入或实际比分。
每条记录包含责任投手、跑者 token、实际得分与影子得分的日志下标、
`earned`、`final`、`reason` 和该投手影子局的 `steps`。
日志下标从 0 开始，对应同次 replay 的 `log`；修改事件后全部重算。
`final` 表示在当前记录不再被编辑的前提下，该分已确定。

每一步记录前后垒位、出局数及判断依据。多个得分共享同一投手轨道的步骤。
真实得分和影子得分必须对应同一个 token 才能产生 ER。

## 判定策略

- 忽略失误进垒；失误上垒及同一打席首次界外漏接补计影子出局。
- 真实跑者不在影子局时，不重复计其出局。
- 封杀检查影子起始垒位、目标垒包及前方受迫链，并按已记录出局顺序解除受迫状态。
- 触杀仅在影子与真实起始垒位一致时采用；明确的裁判跑者出局判罚不受此限制。
- 保送只推进连续受迫链；全垒打让全部影子回垒。
- 普通安打优先使用已记录的正常进垒数。已实际得分、没有后续动作的影子，按安打垒数推定推进。
- 前位跑者优先推进，防止重叠与超越；打者安打占垒所需的额外推进单独记为推定。
- 野手选择替换失误上垒跑者时保留非自责属性。

## 主要原因码

| reason | 含义 |
| --- | --- |
| error-free-score | 真实与影子均已得分 |
| later-legal-advance | 后续正常推进追补 ER |
| reached-on-error | 失误取得上垒机会，或继承该属性 |
| shadow-runner-retired | 跑者已在影子局出局 |
| shadow-inning-ended | 影子三出局前未能得分 |
| not-yet-established | 暂未建立 ER，后续可能改变 |
| insufficient-legal-advance | 半局结束，影子仍未得分 |

步骤中的 `out-not-established` 表示现有输入无法把真实出局直接用于影子局；
`inferred-hit-advance`、`hit-award-displacement`、`inferred-choice-force` 表示推定推进。
这些是确定性的重建策略，不代表输入足以唯一还原所有无失误局面；它们既可能影响
推进，也可能影响影子半局结束时间，不能把所有推定概括为必然降低 ER。
目前仍按半局内投手 ID 建立轨道，未在此次修改中扩展同一投手再次登板的独立阶段。
