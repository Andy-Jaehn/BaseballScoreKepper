# 钻石记分 2.1

- 开赛前从注册表选择记录者和裁判，允许同一人担任；随比赛导出、导入。
- 守备姓名使用固定位置的居中单行框，过长截断；慢投第十个位置为自由人。图中未标出的游击手另保留固定框。
- 慢投不显示触击，并在计算层拒绝触击；封杀目标增加本垒。
- HBP、IBB 和裁判判罚均先显示确认结果，取消恢复操作前状态，未确认状态实时保存。
- IBB 计入 BB，同时分别增加打者 IBB、投手 IBBA，不虚增投球数。按本应用要求，满垒禁止 IBB，不影响普通四坏球及 HBP。该满垒限制是用户指定规则。
- K/9 = 三振 × 27 ÷ 实际取得的出局数，两种运动均按九局口径；无出局数显示 0。
- 判罚进垒有 1、2、3 三个按钮，对所有垒上跑者生效，不自动让打者上垒、不记 RBI。判罚保送单独处理。判罚不虚增投球数。
- 驱逐场上人员进入替补选择；替补继承位置、棒次、垒上跑者责任投手。驱逐本身不额外记出局。工作人员被驱逐时选择接任人员。
- 单列比赛统计：分队展示打击、投球、守备及实际记录到的专项数据。
- 球员统计和比赛记录按开赛年份查看；年度球员 Excel 使用所选年份。
- JSON 支持多选年份导出已结束比赛。比赛身份使用规范化开始时间与结束时间组合，重复导入跳过。按唯一姓名匹配注册球员，缺失球员自动添加并列出提醒。先完整校验和重算，成功后一次性保存，不导入外部累计统计。
